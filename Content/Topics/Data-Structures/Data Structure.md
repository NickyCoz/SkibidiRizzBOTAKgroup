## What are data structures?
Data structures are ways to format data so that a computer program or system can use it effectively and efficiently. 

Data structures allow the user and system to efficiently organize, work with and store data. They make it easier for comptuters to process large sets of information. For the programmers, data structures increase the efficiency of computer code and make the code simpler to understand. 

## Main Categories of Data Structures

Data structures are typically divided into two main categories: linear data structures and non-linear data structures.
