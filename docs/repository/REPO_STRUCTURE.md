## Team logs

```text
Logs/
├── Project/
│   └── YYYY-MM-DD/
│       ├── Project-Log_YYYY-MM-DD.md
│       └── Assets/
│           └── Evidence_L-YYMMDD-E01.png
└── Meetings/
    └── YYYY-MM-DD/
        ├── Meeting-Summary_YYYY-MM-DD_01.md
        ├── Meeting-Summary_YYYY-MM-DD_02.md
        └── Assets/
            └── Evidence_M-YYMMDD-01-E01.png
```

Evidence files belong beside the record they support. Reference image files from the Markdown record with relative paths and captions so they can be included with the relevant entry when the logs are merged into the final deliverable.

## Personal logs

Each member keeps their personal log privately, outside the shared repository.

```text
<Member Name> Personal Log/
└── YYYY-MM-DD/
    ├── Personal-Log_YYYY-MM-DD.md
    └── Assets/
        └── Evidence_P-YYMMDD-01-E01.png
```
