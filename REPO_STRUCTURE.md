# Repository Structure
## Logs
```
Logs/
Logs/
├── Project/
│   └── YYYY-MM-DD/
│       ├── Project-Log_YYYY-MM-DD.md
│       └── Assets/
│           └── Evidence_L-YYMMDD-E01.png
└── Meetings/
    └── YYYY-MM-DD/
        ├── Meeting-Summary_YYYY-MM-DD_01.md
        ├── Meeting-Summary_YYYY-MM-DD_02.md
        └── Assets/
            └── Evidence_M-YYMMDD-01-E01.png
```

Personal logs are done and saved by each member privately. 
Suggested structure:
```
<Member Name> Personal Log/
    └── YYYY-MM-DD/
        ├── Personal-Log_YYYY-MM-DD.md
        └── Assets/
            └── Evidence_P-YYMMDD-01-E01.png
```
